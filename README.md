# T1 Vector Laboratory

Interactive university-level vector laboratory for **The Physics Archive**.

## Sections

- **A — Build a Vector**: components, basis, magnitude, direction, unit vectors
- **B — Combine Vectors**: addition, subtraction, scalar multiplication
- **C — Products**: dot, cross, projection, parallelogram area, triple product
- **D — Index Laboratory**: Einstein summation, Kronecker delta, Levi-Civita symbol
- **E — Rotate the World**: active/passive rotations and invariants
- **F — Mechanics Interpretation**: work, torque, angular momentum

## Run locally

Open `index.html` in a browser. No build step is required.

## GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and `/ (root)`.
7. Save.

GitHub will publish the simulator as a website.

## Notes

The app uses only HTML, CSS, and vanilla JavaScript. Google Fonts are loaded from the web when available.
